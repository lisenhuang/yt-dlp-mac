# Changelog

All notable changes to **yt-dlp-mac** are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project uses date-based (CalVer) release tags generated by the
GitHub Actions [Build & Release](.github/workflows/build.yml) workflow.

## [Unreleased]

### Added

- Full Disk Access guidance for Safari cookies. When a download using
  **From Browser → Safari** fails because macOS blocks access to Safari's
  protected cookie store, the failed download row now explains the cause and
  offers a one-click **Open Full Disk Access** button.
- Settings → Cookies shows a live Full Disk Access status for Safari, with an
  **Open Full Disk Access Settings** button that deep-links straight to the
  System Settings pane.

### Changed

- URL handling now supports multiple YouTube URLs at once, with improved
  extraction logic for pasted and dropped text.

### Fixed

- Safari cookie downloads that failed with
  `Operation not permitted: …/Cookies.binarycookies` now surface a clear,
  actionable explanation — grant Full Disk Access to the app, then fully quit
  (⌘Q) and reopen it — instead of a raw, cryptic error. Granting access to the
  yt-dlp binary alone does not work, because macOS checks the app that launches
  yt-dlp; this is now spelled out in-app and in the README. ([#1])

## [v2026.04.02.2311] - 2026-04-03

### Changed

- Improved cookie diagnostics to give clearer feedback about cookie status.
- Improved the preview experience (preview UX).

## [v2026.03.13.1027] - 2026-03-13

### Added

- Ability to remove active (in-progress) downloads, not just completed ones.

## [v2026.03.13.0506] - 2026-03-13

### Added

- File size and duration are now shown for each item in the download list.

## [v2026.03.12.0622] - 2026-03-12

### Added

- New `completedAt` property on `DownloadItem` to track when a download finishes.
- Download rows now display the completion time in a user-friendly format.

### Changed

- `DownloadManager` sets `completedAt` when a download completes.

## [v2026.03.09.1133] - 2026-03-10

### Documentation

- Expanded README with detailed first-launch instructions for macOS users.
- Added screenshots for clarity.

## [v2026.03.09.1127] - 2026-03-10

### Added

- Cookie management system with selectable cookie sources: from browser,
  from file, or none.
- Picker in Settings for cookie source and browser selection.

### Changed

- `DownloadManager` now handles cookies based on the user's selection.

### Documentation

- Clarified cookie usage instructions and first-launch steps in the README.
- Updated build workflow docs to reflect the new cookie handling.

## [v2026.03.09.1122] - 2026-03-10

### Added

- Auto-installation of yt-dlp on first launch — no manual install required —
  with version fetching and installation-status feedback in the UI.
- Share button in the download row plus a `shareFile` action in
  `DownloadManager` using `NSSharingServicePicker`.
- "Done" button in the Settings toolbar to dismiss the view easily.

### Changed

- Build workflow uses a more precise timestamp format for tags and titles,
  with accurate release notes and installation instructions.

### Documentation

- Updated README to document the auto-install feature and remove the
  outdated manual installation instructions.

## [v2026.03.09-1ecbe17] - 2026-03-09

### Changed

- Renamed the app from `ytdlmc` to `yt-dlp-mac` throughout documentation,
  build scripts, and the GitHub Actions DMG/release process.

### Added

- New app icons in various sizes.

### Documentation

- Enhanced README with updated features, installation instructions, and
  usage guidelines.

## [v2026.03.09-2a8df1b] - 2026-03-09

### Added

- DMG creation in the GitHub Actions workflow for easier distribution.

### Documentation

- Initial comprehensive README covering features, installation, usage,
  and settings.
- Main window and settings screenshots.

## [v2026.03.09-e146097] - 2026-03-09

_First tagged release — the foundation of the app._

### Added

- Core video-downloading functionality:
  - `DownloadManager` to manage downloads, including download path, quality,
    and concurrent-download settings.
  - `DownloadItem` to represent individual downloads with status tracking.
  - `ContentView` for entering URLs, viewing status, and managing downloads.
  - `DownloadRowView` to display each download's status and controls.
  - `SettingsView` for configuring application settings.
- Drag-and-drop URL input and alerts for missing dependencies.
- `.gitignore` and a GitHub Actions workflow for automated building and
  archiving of the Xcode project on push and pull requests to `main`.

### Changed

- Renamed the workflow from "Build" to "Build & Release", added write
  permissions for contents, full-history checkout, a zipped release asset,
  and a step to create a GitHub release with automated tagging and release
  notes on successful `main` builds.
